⚡ Free Cloud Database Integration Guide (Firebase / Supabase)

Right now, all inventory and orders run seamlessly via persistent local storage with reactive `-1` stock deduction. To connect Google Firebase Firestore for team-wide cloud syncing across multiple devices:

  1. Create a free Firebase project at console.firebase.google.com.
  2. Enable Cloud Firestore in test mode.
  3. Paste your Firebase Web configuration keys into assets/js/inventory.js. The system automatically syncs both ways!
